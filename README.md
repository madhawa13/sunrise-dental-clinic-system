# Sunrise Dental Clinic Appointment and Patient Management System

## Module

CIS6003 Advanced Programming

## Project Description

This project is a Java web application developed for Sunrise Dental Clinic in Colombo. The system is intended to replace the clinic's manual appointment, patient-record and billing processes.

## Main Features

- User authentication
- Patient registration and management
- Dentist and treatment management
- Appointment registration
- Unique appointment-number generation
- Prevention of double bookings
- Appointment searching and updating
- Patient treatment records
- Billing and receipt generation
- Help and logout functions
- REST web services
- Automated testing using TDD

## Architecture

The application follows a three-tier architecture:

1. Presentation layer – JSP, HTML and CSS
2. Business layer – Servlet controllers and service classes
3. Data-access layer – DAO classes, JDBC and MySQL

## Technologies

- Java 21
- Jakarta Servlets and JSP
- Apache Tomcat 10.1
- Maven
- MySQL
- JDBC
- JUnit 5
- Mockito
- H2 test database
- Git and GitHub

## Testing

Test-driven development is applied to the DAO, service and controller layers using the Red-Green-Refactor cycle.
